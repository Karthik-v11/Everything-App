# Everything App

## Main features
- Dashboard with weather, todays tasks, News
- Tasks with calender
- Library with bookmarks, to buys, watchlist/tracker, document/password vault section and Projects with document writer
- Finance section to handle the transactions income/outcome/expense

## Other features
- Home screen Widgets
- Push Notification/remainder based on deadlines and set regular notifications
- Local AI model for adding tasks/notes/transactions
- Theme selection
- Share files to this app
